How This Website Works

How this site works — on any phone, tablet, or computer.

  • Works on phone, tablet, and computer: This site is a single, self-contained HTML file with a responsive layout, so text, photos, and the menu adapt to any screen — phone, tablet, or computer.
  • Works in standard browsers: It runs in any standard browser — Chrome, Edge, Safari, or Firefox — with no special app or installation required.
  • Navigation: Use the menu at the top — Home → Attractions → Events → Things to Do → Seasons → Food → Hospitals → Markets → Hotels → Companies → Universities → Houses → Temples & Heritage → Cruise → Cinema → Orlando → Water → Day Trips → Secret Map → Plan Your Visit → Sources. Every link on this page was checked. The top menu stays with you as you scroll.
  • 5 things this website does: 1) It highlights the menu for the section you are reading. 2) The Secret Map lets you search, pick a quest, and pick how far to go. 3) Tap + My Trip to save spots to your own trip list, stored in your browser. 4) The Day Trip finder filters the table as you type. 5) A back-to-top button appears once you scroll down the page.
  • For judges: Links and QR codes are shown on this page. They are not clicked by judges during the presentation, as per the guidelines.
